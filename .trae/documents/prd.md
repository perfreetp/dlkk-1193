## 1. 产品概述

代码质量中心是面向中型研发团队的代码质量管控平台，旨在在迭代开发过程中集中呈现各项目的质量状态，帮助团队及时发现和修复代码问题，降低技术债务，提升交付质量。

- 核心目标：将代码仓库质量数据可视化，实现从"发现问题 → 分派处理 → 跟踪改进"的闭环管理
- 目标用户：研发团队负责人、技术主管、开发工程师、质量保障工程师

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 团队管理员 | 邀请注册 | 管理项目、配置规则、查看全部数据、管理成员 |
| 项目负责人 | 邀请注册 | 管理所辖项目、分派问题、查看团队看板 |
| 开发工程师 | 邀请注册 | 查看个人问题、提交修复说明、查看扫描结果 |

### 2.2 功能模块

1. **项目总览**：项目卡片列表、整体质量评分、快速跳转各项目扫描结果
2. **质量扫描**：接入代码仓库、手动/定时发起扫描、展示重复代码/复杂度/缺陷风险/依赖漏洞/测试覆盖率
3. **问题列表**：按项目/负责人/严重级别/文件路径筛选，支持分派处理人、设置截止时间、记录修复说明
4. **规则配置**：为不同项目启用不同检查项和阈值
5. **改进计划**：将问题打包成阶段目标，跟踪完成率
6. **团队看板**：展示趋势图表、排行榜、未处理风险，支持复盘

## 3. 核心流程

用户接入代码仓库后，手动或通过定时任务触发扫描，系统执行质量分析并生成问题列表。用户在问题列表中筛选、分派问题，或将问题打包成改进计划。负责人通过团队看板查看整体趋势和风险，进行复盘决策。

```mermaid
flowchart TD
    "接入仓库" --> "配置规则与阈值"
    "配置规则与阈值" --> "发起扫描"
    "发起扫描" --> "扫描分析"
    "扫描分析" --> "生成问题列表"
    "生成问题列表" --> "筛选与分派"
    "筛选与分派" --> "修复问题"
    "修复问题" --> "记录修复说明"
    "生成问题列表" --> "打包改进计划"
    "打包改进计划" --> "跟踪完成率"
    "跟踪完成率" --> "团队看板复盘"
    "修复问题" --> "团队看板复盘"
    "团队看板复盘" --> "调整规则"
    "调整规则" --> "发起扫描"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色科技风，主色使用深青色 (#0F172A) 配合荧光青色 (#06D6A0) 作为强调色，辅以琥珀色 (#F59E0B) 表示警告、红色 (#EF4444) 表示严重
- **按钮风格**：圆角微立体按钮，悬浮时有荧光发光效果
- **字体**：标题使用 DM Sans (Bold/ExtraBold)，正文使用 Plus Jakarta Sans (Regular/Medium)，代码使用 JetBrains Mono
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式模块布局，网格化信息展示
- **图标风格**：线性图标配以微光效果，使用 Phosphor Icons 风格

### 4.3 响应式设计

- 桌面优先设计，1920px 为最佳视口
- 1440px 以下项目卡片从3列调整为2列
- 1024px 以下侧边导航折叠为图标模式
- 移动端暂不作为主要适配目标，保持基本可用即可
